`bash checks/baseline.sh` compiles the upstream C sources directly. The local
config_types.h supplies the C99 exact-width types normally generated by configure.
Only a C11 compiler, standard C library, Bash and awk are used. No packages or
runtime resources are downloaded. Both upstream embedded selftests are executed.

The baseline is generic Ogg framing, not an Opus decoder or a new repaginator.
Its 8192-byte payload is a deterministic opaque byte string. The fill hint is
intentionally smaller than the resulting page. This is existing documented
behavior, not a bug assertion. New Opus timing and bounded repagination remain
unimplemented.

The target directly compiles the new C implementation and C contract tests.
The test driver owns main and counters; tests register named functions in paging,
timing and streaming. Each function must perform real contract_expect assertions.
The parent process validates all group completions and final completion in raw
stdout, after checking the actual process exit code. Do not weaken the driver.
