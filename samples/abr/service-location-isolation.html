Isolation of throughput estimates per service location

When a stream is served from multiple CDNs, measurements from a fast location should not be used to select a high bitrate after switching to a slow one. Enabling streaming.abr.throughput.isolateByServiceLocation keeps the throughput, latency and EWMA estimates per service location. Switching back to a location restores its original samples.

Use player.getCurrentServiceLocation(dashjs.Constants.VIDEO) to query the location of the most recently accepted media segment. The value is null before the first media sample and an empty string for segments without a service location.
