ogg_mux_end_input

declared in "ogg/mux.h";

Declares that no more pages or watermarks will be submitted. If any track has not accepted an EOS page, OGG_MUX_INCOMPLETE is returned and the instance stays usable; otherwise the instance is closed and later submissions or watermark calls are rejected with OGG_MUX_INVALID. Calling it again after a successful close is harmless. 


ogg_mux_result_t ogg_mux_end_input(ogg_mux_t *mux);

Parameters

mux
The multiplexer instance.

Return Values

  • OGG_MUX_OK: every track reached EOS and input is closed.
  • OGG_MUX_INCOMPLETE: at least one track has no EOS.
  • OGG_MUX_INVALID: NULL instance.
