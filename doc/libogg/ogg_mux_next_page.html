ogg_mux_next_page

declared in "ogg/mux.h";

Returns the next page that may safely be written.

All BOS pages are delivered first, in registration order, and only after every track has supplied one. After that, non-BOS pages are delivered in increasing scheduling time; ties follow registration order, and each track's pages stay in their submitted order. Delivery requires every track that has not accepted EOS to have committed a watermark no earlier than the candidate page's time, and requires that no track is holding an unanchored group. When no page is safe the function returns OGG_MUX_AGAIN; it never forces output.

The returned page points into instance-owned storage. It is valid only until the next operation that changes the instance (submit_page, advance_frontier, set_limit, end_input, destroy) or the next successful fetch. 


ogg_mux_result_t ogg_mux_next_page(ogg_mux_t *mux, ogg_page *page);

Parameters

mux
The multiplexer instance.
page
Receives borrowed pointers to the next safe page.

Return Values

  • OGG_MUX_OK: a page was returned.
  • OGG_MUX_AGAIN: no page is safe yet.
  • OGG_MUX_INVALID: NULL argument.
