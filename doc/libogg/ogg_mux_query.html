ogg_mux_track_count / ogg_mux_bytes

declared in "ogg/mux.h";

Two accessors for diagnostics. ogg_mux_track_count returns the number of registered tracks. ogg_mux_bytes returns the number of page bytes currently held, including an unanchored group and a page still borrowed from the last fetch. 


int ogg_mux_track_count(const ogg_mux_t *mux);
size_t ogg_mux_bytes(const ogg_mux_t *mux);

Parameters

mux
The multiplexer instance; NULL yields 0.
