ogg_mux_advance_frontier

declared in "ogg/mux.h";

Raises a track's watermark. The value is a time in that track's own tick units: after the call every non-BOS page subsequently submitted for the track must schedule strictly later than ticks. Watermarks are monotonic; a lower value is rejected. Queued pages are not affected. Once a track has accepted EOS, setting its watermark is a no-op because such a track is treated as an infinite watermark. 


ogg_mux_result_t ogg_mux_advance_frontier(ogg_mux_t *mux, int serial,
                                          ogg_int64_t ticks);

Parameters

mux
The multiplexer instance.
serial
Serial number of the track to advance.
ticks
New watermark in the track's time base; non-negative.

Return Values

  • OGG_MUX_OK: accepted.
  • OGG_MUX_BAD_SERIAL: unknown serial number.
  • OGG_MUX_INVALID: negative value, a lower value than already committed, or input already ended.
