ogg_mux_set_limit

declared in "ogg/mux.h";

Changes the number of bytes of page header plus body the instance may hold. Raising the limit is always allowed. Lowering it below the number of bytes currently held, including an unanchored group or a page still borrowed from the last fetch, is rejected and the previous limit is kept. 


ogg_mux_result_t ogg_mux_set_limit(ogg_mux_t *mux, size_t limit);

Parameters

mux
The multiplexer instance.
limit
New byte limit.

Return Values

  • OGG_MUX_OK: limit changed.
  • OGG_MUX_CAPACITY: the new limit is below the bytes held.
  • OGG_MUX_INVALID: NULL instance.
