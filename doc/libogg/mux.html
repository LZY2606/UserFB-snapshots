Multiplexing

The multiplexer combines several already-framed logical Ogg bitstreams into one physical stream. It operates on complete pages: it never re-packetizes, rewrites, or interprets page payloads, and it does not change the layout of any existing structure. Pages handed to it must come from the regular encoding layer, so their structure and CRC are already valid.

The public interface is declared in ogg/mux.h. An instance is an opaque ogg_mux_t. Every operation returns an ogg_mux_result_t, which is OGG_MUX_OK on success or one of the failure codes listed on the individual pages.

Interleaving is decided by scheduling time, never by the order in which pages happen to arrive. Each track is registered with a rational time base (numerator and denominator, both positive); a page's scheduling time is granule × num / den, compared exactly in integer arithmetic without floating point. All BOS pages are written first, in registration order, once every track's BOS has arrived. After that, pages are written in increasing time, with ties broken by registration order, while each track keeps its own page order.

Watermarks

A watermark W promises that every non-BOS page for that track submitted later will schedule strictly after W. A pending page may be delivered only when every track that has not yet accepted EOS has committed a watermark no earlier than that page's time, and no track is holding an unanchored group. A watermark only constrains future submissions; queued pages are unaffected. Accepting a track's EOS is equivalent to committing an infinite watermark for it.

A page whose granule is −1 is a page on which no packet completed. A run of such pages is grouped with the next page of the same track that has a non-negative granule; all of them use that page's time for scheduling while keeping their original granule bytes.

Ownership

A successful ogg_mux_submit_page copies the page, so the caller may reuse its buffer immediately. A page obtained from ogg_mux_next_page is borrowed: it stays valid until the instance is next changed.

Function reference

function purpose
ogg_mux_create Create a multiplexer with fixed track parameters.
ogg_mux_destroy Release an instance and everything it holds.
ogg_mux_submit_page Submit one complete page for one track.
ogg_mux_advance_frontier Advance a track's watermark.
ogg_mux_set_limit Change the byte limit for held pages.
ogg_mux_next_page Fetch the next page that is safe to deliver.
ogg_mux_end_input Declare that no more input will arrive.
ogg_mux_track_count, ogg_mux_bytes Query instance properties.

Example

The following fragment multiplexes two tracks page by page. Input pages are assumed to have been read elsewhere; output pages are written to out. 

#include <ogg/mux.h>

int serials[2] = { 101, 202 };
ogg_int64_t num[2] = { 1, 1 };
ogg_int64_t den[2] = { 48000, 48000 };
ogg_mux_t *mux = ogg_mux_create(2, serials, num, den, 1 << 20);
ogg_page page;
ogg_mux_result_t r;
int i;

if (!mux) return -1;

for (i = 0; i < 2; i++) {
  /* The BOS page of each track, obtained from the caller's sync layer. */
  ogg_page bos = next_input_page(i);
  if (ogg_mux_submit_page(mux, &bos) != OGG_MUX_OK) return -1;
}

for (;;) {
  /* Submit a page from any track, then drain everything now safe. */
  ogg_page in = next_input_page(-1);
  r = ogg_mux_submit_page(mux, &in);
  if (r == OGG_MUX_CAPACITY) {
    /* Raise the limit, then resubmit the same page unchanged. */
    if (ogg_mux_set_limit(mux, 1 << 22) != OGG_MUX_OK) return -1;
    continue;
  }
  if (r != OGG_MUX_OK) break;

  while ((r = ogg_mux_next_page(mux, &page)) == OGG_MUX_OK) {
    write_page(out, &page);      /* page is borrowed; copy if kept */
  }
  if (r != OGG_MUX_AGAIN) return -1;

  /* Advertise how far this track has been read.  The value is a time
     in the track's time base, not a granule. */
  ogg_mux_advance_frontier(mux, last_serial, last_time);
}

if (ogg_mux_end_input(mux) != OGG_MUX_OK) return -1;
while ((r = ogg_mux_next_page(mux, &page)) == OGG_MUX_OK)
  write_page(out, &page);

ogg_mux_destroy(mux);

A complete command-line driver is built as oggmux; see examples/oggmux.c. It reads page and control records on stdin and writes the multiplexed physical stream on stdout.
