ogg_mux_create

declared in "ogg/mux.h";

Creates a multiplexer and fixes the immutable per-track parameters for its lifetime. All tracks' serial numbers must be distinct. num and den are positive rational time bases; a page's scheduling time is granule × num / den. limit is the maximum number of bytes of page header plus body the instance may hold at once.

The instance owns no caller memory; every accepted page is copied. There is no thread synchronization inside the instance. 


ogg_mux_t *ogg_mux_create(int track_count, const int *serials,
                          const ogg_int64_t *num, const ogg_int64_t *den,
                          size_t limit);

Parameters

track_count
Number of tracks; must be positive.
serials
Array of track_count serial numbers, all distinct.
num, den
Arrays of track_count positive time-base numerator and denominator values. Both may use the full signed 64-bit range.
limit
Maximum bytes of page header plus body held at once; must be positive.

Return Values

  • A new instance, or NULL on invalid parameters or allocation failure.
