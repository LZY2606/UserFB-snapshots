# Geometric color-font input

The 968-byte font and its generator are original MIT-licensed test material, not derived from a real font. `node colrcheck/make-font.mjs --check` compares all bytes; without `--check` it regenerates the TTF and table/node manifest. Requires Node.js >=18 built-ins only. No npm packages, system fonts, submodules or network services are used.

Glyph 2 (`@`, `d`, `u`) is an 800-unit square; glyph 3 is its inset square; glyph 4 is a half-width square. Glyphs 1 (`A`), 5, 6 and 7 have empty glyf data and COLRv1 roots. Root 1 has solid red with a half-alpha blue inset. Root 5 has a three-point linear gradient; root 6 references it twice under distinct affine contexts; root 7 combines an inset gradient with a half-alpha square using SRC_IN. Two CPAL v0 palettes include different RGB and alpha entries. `font-manifest.json` lists relative COLR node offsets and absolute sfnt table offsets.

`baseline.c` calls existing stb_truetype APIs and reports the old monochrome behavior. It contains no COLRv1 evaluator. `check-old.sh` executes the upstream TrueType sample (including SDF, atlas and bitmap calls) with this font, then compiles the original sample in both C99 and C++11 declaration modes. This is an existing example smoke check, not a claim that upstream has a comprehensive TrueType assertion suite.

The requested color API, contract tests and preview example are intentionally absent from the starting tree. The target runner rejects missing tests, no executed checks and skip output.

## Added COLR v1 support

`stb_truetype.h` now provides `stbtt_MakeGlyphCOLRBitmap()`, a self-contained
static-paint evaluator for CPAL v0 palettes and COLR v1 paint graphs (no
FreeType, browser or other rendering dependency). The supported paint formats
are PaintColrLayers (1), PaintSolid (2), PaintLinearGradient (4, PAD only),
PaintGlyph (10), PaintColrGlyph (11), PaintTransform (12) and PaintComposite
(32, SRC_OVER/SRC_IN). Output is premultiplied RGBA8 in channel order R,G,B,A.

`fixtures/contract.ttf` and `fixtures/errors.ttf` are generated by
`make-font.mjs` alongside `geometry.ttf` (whose bytes never change). The
contract font covers outline-only vs fill-only transforms, three-point
non-orthogonal gradients, non-commuting nested transforms, isolated SRC_IN
with an outer sibling, translucent SRC_OVER, clip restore, shared subgraphs,
palette switching and caller-foreground color stops. `fixtures-manifest.json`
records layout details and hashes; `node colrcheck/make-font.mjs --check`
verifies all three fonts byte-for-byte.

- `tests/colr_v1_contract.c` is the pixel contract suite. It compiles as C99
  and C++11, keeps its assertions under `-DNDEBUG`, and takes
  `--case gradient_transform|isolated_composite|shared_graph|legacy_and_errors`.
  Reference values come from independent `double` formulas, and grayscale
  coverage is cross-checked against the legacy rasterizer.
- `examples/colr_preview.c` writes a binary P6 PPM of one icon in two
  palettes, compositing transparency over a checkerboard. Run it with an
  output path argument.

Run `bash colrcheck/install.sh` once, then `bash colrcheck/run-target.sh`
for the full C99/C++11/ASan+UBSan contract run, the preview build and the
legacy smoke checks. `bash colrcheck/baseline.sh` continues to pass
unchanged.
