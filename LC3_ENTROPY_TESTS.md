# LC3 Spectral Entropy Content Regression

This directory adds a self-contained, Python-free content regression for the
LC3 spectral entropy layer.  The normal algorithm, the public ABI and the
existing tests are unchanged; the only production source touched is
`src/spec.c`, and solely behind the `LC3_ENTROPY_TRACE` test macro.

Everything is built with the C/C++ compiler and the system math library.
No package is installed, no audio is downloaded and the Python test framework
is never executed.

## Files

| File | Role |
| --- | --- |
| `entropy_reference.cpp` | Independent entropy model: own byte array, end-to-start plain-bit cursor, standalone 24-bit interval encoder/decoder, spectral and whole-frame reference parsers. |
| `target_bridge.c` | Plain-C translation unit that `#include`s `../src/spec.c` to expose its file-local stages, plus the read-only `LC3_ENTROPY_TRACE` observation storage. |
| `target.cpp` | Test driver. Includes `checks.h`, defines `void task_run(const char*)`, defines no `main`, and records every comparison through `TASK_CHECK`. |
| `target.sh` | Fixed entry point (unchanged): runs `planes`, `spectrum`, `frames`, then the `context` and `lsb-sign` mutants, then the baseline. |

## Boundaries of the independent model

The reference deliberately re-implements rather than calls the production
code:

- It owns the packet bytes and a plain-bit cursor that walks from the last
  byte toward the first, LSB first (`er_bits_*`).
- The arithmetic coder is a standalone 24-bit interval coder.  Symbols are
  selected by a **linear interval search** over the model cumulative bounds
  (`er_ac_dec_symbol`), not the production binary-search fast path.
- The encoder keeps its own `cache / carry / carry_count` state and its own
  termination routine, including the merge of the fractional termination
  byte with the backward plane.
- It never calls the production `bits`/`spec` readers, writers, budget or
  termination functions and does not copy their caches or look-up code.
- The only production data it reads are format tables: the probability
  distributions `lc3_spectrum_models`, `lc3_tns_*_models`, the spectral
  context table `lc3_spectrum_lookup`, and the inline geometry helper
  `lc3_ne`.  Gain is evaluated with a double precision `pow(10, g/28)`.

MDCT, SNS, TNS filtering and PLC are not re-implemented.  Non-target frame
fields are produced with the existing SNS/TNS writers, and PCM round trips
are never treated as lossless.

## Groups

### planes

Bit-level cross checks, in both directions:

- bytes generated by the standalone coder are read by the production reader;
- bytes generated by the production writer are read by the standalone reader.

The event plan is searched deterministically until one stream really raises a
carry **and** holds at least two consecutive pending `0xff` bytes.  Dedicated
cases also cover the arithmetic termination bit sharing the last byte with
the backward plane, and non-byte-aligned plain runs that cross the 32-bit
accumulator (a 70-bit sequence of mixed widths).  Comparisons are on the
actual symbol values, plain bit values and the logical number of remaining
bits, never on a same-library round trip.

### spectrum

Real spectral streams are built from explicit signed coefficient plans and
parsed independently.  Scope is ordinary LC3 only: 7.5/10 ms and
8/16/24/32/48 kHz; high-resolution mode is not exercised.

Branches that are provably reached (each is backed by an assertion on the
decoded trace, not assumed):

- front/back spectral-half context model switch (`second_half_pairs > 0`);
- both sides of the high-rate gate (`resolve_modes`, including the
  `nbytes == 20*(1+sr_ind)` boundary value where the gate stays off);
- at least two escape levels on one coefficient (`max_escape >= 2`);
- residual correction with LSB disabled (`residual_applied > 0`);
- LSB enabled, with high bits zero and the low plane recovering both
  positive and negative unit coefficients (`lsb_unit_pos/neg > 0`);
- deferred-plane budget exhaustion, stopping inside a pair or before a
  symbol, without using padding zeroes to invent unconsumed symbols
  (`budget_stop`, `stop_pair`, `stop_phase`).

Integer quantized values and the post-residual/LSB values are compared for
exact equality; the noise seed, noise fill and gain-scaled spectrum are
compared coefficient by coefficient with a final float tolerance of
`2e-5 * (1 + |reference|)`.  All vectors are generated deterministically.
On failure the report prints duration, rate, packet length, coefficient
position and the first deviation, prefixed `LC3_ENTROPY_MISMATCH`.  No hash
of production output is frozen as an expectation.

### frames

The model is connected back to the public `lc3_decode()` entry point on
complete, legal frames whose side information comes from explicit plans.

- At least one frame carries a non-zero TNS filter; its arithmetic symbol
  prefix shares the single interval state with the spectrum.  The
  standalone reader advances from byte 0 through the side information and
  the TNS symbols itself, never from a production cursor or snapshot.
- Under `LC3_ENTROPY_TRACE`, `lc3_spec_decode()` calls a read-only hook that
  snapshots the spectrum after spectral decode and before TNS synthesis.
  The normal build defines no macro, adds no state, callback or allocation.
  The snapshot is compared coefficient by coefficient with the independent
  frame parse.
- Checks then cover a run of consecutive non-zero PCM samples, the output
  sample count, the stride-2 protected region (the guard lane must remain
  untouched), and two decoder instances interleaved on one buffer.
- A deliberately constructed runaway-escape packet exhausts the bit budget
  and is confirmed to drive the public entry into PLC: its PCM is compared,
  for the loss frame and the following good frame, against a twin instance
  fed an explicit `NULL`.  This is a constructed exhaustion, not an assumed
  single-bit flip.

## Mutation detection

`target.sh` builds two temporary copies with `mutate.awk` and runs the
`spectrum` group on each.  A content failure must start with
`LC3_ENTROPY_MISMATCH` and exit with status 2; any other exit is not counted
as a detected problem.

- `context` drops the `(state << 4)` history contribution in
  `get_quantized`; the independent context evolution diverges and the
  residual-stage comparison fails.
- `lsb-sign` forces the recovered negative unit LSB coefficient positive;
  the independent sign interpretation keeps `-1`, so the mismatch is
  reported at the unit coefficient (observed at coefficient 6 of the
  `lsb-units` case).

## What the upstream tests do not cover

The upstream suite primarily compares each production stage against the
Python reference module or exercises full-frame round trips.  It does not
provide:

- a second, independent interval coder (own carry/pending/termination
  implementation) cross-checked byte-for-byte against the production layer
  in both directions;
- explicit assertions on pending `0xff` runs, the shared termination byte
  and unaligned 32-bit accumulator crossing as isolated phenomena;
- per-coefficient exact checks driven by an explicit signed plan with
  documented half-model, high-rate, escape, residual, LSB and truncation
  branch evidence;
- a frame-level check that an exhausted packet and an explicit `NULL` loss
  produce identical PLC PCM on identical histories;
- the two targeted entropy mutations used here as regression sentinels.

## Running

```sh
bash task_support/target.sh
```

The script finishes with
`LC3_ENTROPY_SUITE_COMPLETE groups=3 mutants=2` on success.  `baseline.sh`
remains the compatibility reference and is run unchanged at the end.
