The data-only ELF material is generated by fixture.h using fixed byte layouts.
Both objects contain the same CU and standard location list. The second object
adds GNU view_pair prefixes, a producer extension currently not read by this snapshot.

Producer format references (documentation only, no runtime network access):
https://gcc.gnu.org/legacy-ml/gcc-patches/2017-11/msg00820.html
https://github.com/gcc-mirror/gcc/blob/master/include/dwarf2.h

These support files contain no implementation of the requested reader.
