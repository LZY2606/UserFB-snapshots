Build with a C++17 standard compiler. No external dependencies, scene downloads or GPU are required. `bash task_support/run.sh build` compiles every src/*.cpp except MiniLight.cpp into production objects, then builds the original CLI and the numerical legacy baseline. `bash task_support/run.sh baseline` runs that baseline, two upstream scenes and the CLI.

Write the future tests/gradient_transport.cpp without main. Include task_support/check.h and production headers, define task_cases and task_case_count, and register the four group names in prompt.md. Each case returns zero and uses TASK_CHECK for content assertions. The target command is `bash task_support/run.sh target`; the actual new test file is compiled and linked against production objects, including new src/*.cpp files. Missing/empty files, zero cases, missing groups, absent assertions and early exit cannot pass. A successful target run then also runs the original baseline.

Only the 96-line legacy baseline.cpp was reused from an earlier public scaffold at the same upstream commit. Its guiding implementation and target tests were not copied. The target gradient feature, solver and target tests are intentionally absent. Keep all upstream source, scenes and LICENSE.txt.
